# 모바일 자동 영상 편집기 현행 구현·검증 계획

최초 작성일: 2026-08-01  
현행화: 2026-08-02  
기준 시간대: Asia/Seoul (KST)

## 1. 현재 제품 구조

- Flutter 앱이 원본을 내려받아 편집 프로젝트와 미리보기를 관리한다.
- Android Media3가 컷 연결, 캔버스 합성, 줌, 텍스트와 최종 MP4 저장을 담당한다.
- 서버 자동 편집 API는 `짧게`, `중간`, `길게` 추천 컷과 추천 줌을 제공한다.
- STT, 자동 자막, Banuba, 온디바이스 Whisper는 현재 제품 범위에서 제거했다.
- 사용자가 직접 넣는 텍스트 레이어만 제공한다.

상세 구현 계약은 `자료/docs/21_모바일_자동_영상_편집기_구현.md`와
`frontend/VIDEO_EDITOR.md`를 기준으로 한다.

## 2. 편집 화면 계약

### 컷

- 컷 탭만 상세 프레임 타임라인을 표시한다.
- 재생 위치는 `HH:MM:SS:FF`와 30fps 프레임 번호로 표시한다.
- `-1f`, `+1f`, 핀치, `1x/2x/4x/8x` 확대를 제공한다.
- 다중 클립은 `클립 1/2` 고정 표시와 카드 채움으로 현재 대상을 구분한다.
- 각 클립 카드는 원본 기준 `시작–끝` 범위를 표시한다.
- 같은 원본에서 한 프레임 이내로 이어진 클립은 경계에서 다시 seek하지 않는다.
- 프리셋 변경은 사용자가 만든 다중 클립 배열을 삭제하지 않는다.

### 캔버스

- 화면 비율과 가로 영상 표시 영역만 설정한다.
- 자동 편집 진입 기본값은 9:16 세로 캔버스와 가로 영상 전체 보기다.
- 가로 영상은 고정된 영상 창 안에 남고 위아래 검은 영역을 침범하지 않는다.

### 구간 줌

- 확대, 좌우·상하 이동, 회전과 구간 줌을 한 탭에서 조작한다.
- 현재 위치에 줌 구간을 추가하고 프레임 경계로 시작·끝을 조절한다.
- 추천·수동 줌의 배율과 초점 X/Y를 수정하거나 삭제한다.
- 탭마다 별도 키를 사용해 이전 탭의 스크롤 위치가 재사용되지 않게 한다.

### 텍스트

- 상단 추가 버튼으로 영상 위에서 바로 입력한다.
- 만든 레이어는 가로 카드로 다시 선택하고 수정한다.
- 키보드가 열리면 타임라인과 도구 트레이를 접어 미리보기 공간을 보존한다.

## 3. 검증 명령

```bash
cd frontend
flutter pub get
flutter analyze
flutter test
flutter run -d R3CX20N6L2Z --debug --no-resident
```

- APK/AAB는 CI나 작업 과정에서 생성하지 않는다.
- 실제 기기 확인은 Galaxy S24+ (`SM-S926N`)에서 `flutter run`으로 수행한다.
- MR은 구조 개편 검증이 끝나기 전까지 생성하지 않는다.

## 4. 필수 회귀 검증

1. 360×660부터 412×915까지 모든 탭에 RenderFlex overflow가 없어야 한다.
2. 프레임 버튼과 컷·줌 손잡이는 30fps 경계에 맞아야 한다.
3. 다중 클립에서 프리셋을 바꿔도 클립 개수와 순서가 유지돼야 한다.
4. 인접 클립 재생은 경계에서 멈춤이나 같은 프레임 재탐색이 없어야 한다.
5. 클립 카드를 누르면 선택 번호와 미리보기가 함께 이동해야 한다.
6. 컷 외 탭에는 프로젝트 개요 바가 남지 않아야 한다.
7. 캔버스 탭에는 비율·표시 영역만, 구간 줌 탭에는 이동·확대·회전·줌만 보여야 한다.
8. 구간 줌 탭을 왕복해도 추가 버튼과 모든 조절기가 즉시 눌려야 한다.
9. 9:16 저장 결과에서 가로 영상 줌이 위아래 검은 영역으로 나오지 않아야 한다.

## 5. 현재 남은 확인

- 서로 다른 원본 또는 순서를 바꾼 클립의 경계는 seek가 필요하므로 실기기 체감 확인이 필요하다.
- 긴 영상의 8배 타임라인 확대에서 썸네일 72장 상한이 충분한지 추가 확인한다.
- Media3 저장 결과와 Flutter 미리보기의 이동·회전·줌 오차를 대표 영상별로 비교한다.
