# llm — LLM 협업 전략과 산출물

이 폴더는 LLM(Claude, Codex 등)과 협업할 때 쓰는 규칙과 세션 산출물을 모은다.
Jetson AI 제품 코드는 `ai/`에 있으며, 이 폴더와 무관하다.

## 구성

- `GIT_BRANCH_RULES.md` — Git 브랜치 규칙 한국어 원본.
  루트 `AGENTS.md`는 이 문서의 영문 요약이며, LLM 도구가 저장소를 열 때
  자동으로 읽는 진입점이므로 루트에 남긴다.
- `handoff/` — LLM 세션 간 인수인계 문서와 통합 보고서.
  파일 이름에 날짜를 붙인다 (예: `..._HANDOFF_20260729.txt`).

## 규칙

- 새 인수인계 문서는 `handoff/`에 만들고, `ai/`나 루트에 두지 않는다.
- 코드의 동작을 설명하는 문서는 여기가 아니라 `자료/docs`에 쓴다.
  이 폴더는 "LLM과 어떻게 일하는가"에 대한 문서만 담는다.
