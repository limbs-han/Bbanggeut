# 요구사항 명세서

> 기준: 5979279 / 2026-07-27 / 구현 코드 기준(as-built)

본 문서는 다음 산출물을 근거로 작성되었으며, 추측 없이 코드에서 직접 확인된 사실만 기재한다. 확인 불가 항목은 `⚠️ 미확인`으로 표시한다.

- `docs/human/03-기능명세서.md` — 기능 ID 체계(FN-A01~A37 앱 37개, FN-S01~S25 서버 25개, FN-E01~E10 엣지 10개, FN-H01~H04 하드웨어 4개, 총 76개). 본 문서의 "관련 기능" 열은 이 ID를 그대로 사용한다.
- `docs/human/04-API명세서.md` — API-01~50, MQTT-01~15.
- `docs/superpowers/plans/2026-07-27-inventory/backend.md`, `cross-check.md` — 비기능 요구사항(보안·운영 설정) 및 구현 상태 판정 근거.
- 저장소 직접 확인: `.gitlab-ci.yml`, `backend/deploy/*`(nginx, docker-compose, backup 스크립트, systemd 유닛), `backend/server/src/main/resources/application.yml`.

기능 요구사항은 기능 명세서의 FN 항목을 사용자 관점 문장("사용자는 ~할 수 있다")으로 상향 기술한 것이며, 여러 FN이 하나의 사용자 요구로 묶이는 경우가 많다(예: 앱 화면 1개 + 서버 API 1개 + 엣지 동작 1개가 "실시간 시청"이라는 요구 하나를 구성). 하나의 FN이 서로 다른 REQ 여러 개에 걸쳐 등장하는 경우도 있다(예: FN-A24는 소유권 이전과 구성원 추방 두 요구에 모두 관련).

**우선순위 기준**(2026-07-27 확정, 시연 기준 MVP): 우선순위는 **MVP / MVP(전제) / 확장** 3단계다.
- **MVP** — 시연 필수 7항목에 직접 해당: ① 회원가입/로그인(REQ-F-01·02) ② 기기 등록(REQ-F-10) ③ 홈 라이브 스트리밍(REQ-F-18) ④ 이벤트 감지 영상 확인(REQ-F-37·21·22) ⑤ 영상 편집(REQ-F-27) ⑥ 편집 영상 다운로드(REQ-F-26) ⑦ 통계/리포트(REQ-F-19·36 현행 + REQ-F-42 신규 리포트 화면).
- **MVP(전제)** — 7항목에 직접 명시되진 않았지만 시연 동선에 필수인 기반: 세션 유지(REQ-F-03), 기기 목록/상태(REQ-F-12), 탭 셸(REQ-F-41).
- **확장** — MVP 외 전 항목(초대/구성원, 구독, 소유권 이전, 팬틸트 등).

**MVP 충족 판정 기준**(확정): ⑤편집·⑥다운로드는 **로컬 편집 + 기기 저장이면 충족**(서버 재업로드 불요). ⑦통계는 **현행 캘린더 집계(REQ-F-19)와 웃음 통계(REQ-F-36)로 충족**하되, 이벤트 영상 기반 전용 리포트 화면(REQ-F-42)을 신규 개발 항목으로 병행한다.

**구현 상태 판정 원칙**: `cross-check.md`의 사용 상태(✅42/🔶7/🔴1, MQTT 15행)와 기능 명세서 2~5절의 서술을 그대로 따른다. 확정된 특이 사항:
- 프로필 수정(서버 부재)과 프런트 전용 스텁 4기능(소셜 로그인, 비밀번호 찾기/변경, 기념일 저장)은 미구현 또는 부분으로 표기한다.
- `homecam/v2` 웃음 감지 확장 MQTT 파이프라인(이벤트 퓨전 등)은 코드는 완성되어 있으나 운영 배포에서 비활성화되어 있으므로 부분(🔶)으로 표기한다.
- 팬틸트 자동 추적은 발행부만 존재하고 구독/모터 구동 코드가 없어 미구현(❌)으로 표기한다.
- `LiveScreen`(FN-A12) 자체는 어디서도 호출되지 않는 도달 불가 코드이지만, 그 기능(임베디드 실시간 시청)은 `EmbeddedLivePlayer`로 실제 구현되어 있으므로 "실시간 시청" 요구는 구현됨(✅)으로 판단하고, `LiveScreen` 미사용 사실은 근거란에만 별도 표기한다.
