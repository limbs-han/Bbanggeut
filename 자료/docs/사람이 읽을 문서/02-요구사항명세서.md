본 문서는 **목표(to-be) 기준**의 요구사항 명세서다. `01-서비스기획.md`에서 확정한 MVP 7단계를 뼈대로, 사용자가 이 서비스로 무엇을 할 수 있어야 하는지를 정의한다. 구현 상태(✅/🔶/❌)는 본문에 넣지 않고 문서 말미 **부록 B**에만 별도로 요약한다.

- 기능 요구사항(REQ-F)의 ID는 기존 as-built 문서에서 사용하던 번호를 그대로 재사용한다(REQ-F-01~42). 문서 배치는 MVP 7단계 순서로 재구성했지만 번호 자체는 바뀌지 않았다 — AI용 문서·기존 이력과의 추적성을 유지하기 위함이다.
- "관련 기능" 열은 `03-기능명세서.md`의 FN ID(FN-A: 앱, FN-S: 서버, FN-E: 엣지, FN-H: 하드웨어)를 그대로 사용한다.
- MVP 범위 밖이지만 문서·기능 자체는 유지하는 항목은 **부록 A(확장 요구사항)**로 옮겼다. 가족 공유는 홈캠 서비스 특성상 MVP 7단계는 아니지만 본문(1.8)에 유지한다.

## 1. 기능 요구사항 (REQ-F)

### 1.1 회원가입 / 로그인

사용자는 이메일과 비밀번호만으로 계정을 만들고 로그인한다. 소셜 로그인과 비밀번호 찾기는 MVP 범위 밖이다(부록 A).

| ID | 요구사항 | 관련 기능 |
|---|---|---|
| REQ-F-01 | 사용자는 이메일·비밀번호·표시 이름으로 신규 계정을 만들 수 있다. | FN-A03, FN-S01 |
| REQ-F-02 | 사용자는 이메일·비밀번호로 로그인할 수 있고, 로그인 실패가 반복되면(5회/10분) 일시 차단된다. | FN-A02, FN-S01 |
| REQ-F-03 | 사용자는 앱을 재실행해도 로그인 세션이 유지되고, 공유받은 초대 딥링크(`bbanggeut://`)로 앱에 바로 진입할 수 있다. | FN-A01 |
| REQ-F-04 | 사용자는 로그아웃하여 현재 세션을 종료할 수 있다. | FN-A32, FN-S02 |
| REQ-F-05 | 사용자는 소유 중인 기기가 없을 때 회원 탈퇴(계정 삭제)를 할 수 있다. | FN-A33, FN-S02 |

### 1.2 기기 등록

사용자는 새 Jetson 기기를 QR 코드 또는 8자리 코드로 자신의 계정에 등록한다. 등록된 기기는 이후 OWNER가 이름·보관 기간 등을 관리할 수 있다.

| ID | 요구사항 | 관련 기능 |
|---|---|---|
| REQ-F-10 | 사용자는 QR 코드 스캔 또는 8자리 등록 코드 직접 입력으로 홈캠 기기를 계정에 등록할 수 있다. | FN-A07, FN-S04, FN-S20, FN-S21, FN-E01, FN-E02 |
| REQ-F-12 | 사용자는 자신이 접근 가능한 기기 목록과 온라인/오프라인 상태를 확인할 수 있다. | FN-S03, FN-S05, FN-S25, FN-E03 |
| REQ-F-13 | 사용자는(OWNER) 기기 이름과 영상 보관 기간(1~3650일)을 변경할 수 있다. | FN-A27, FN-S05 |

### 1.3 홈에서 라이브 스트리밍 시청

사용자는 홈 화면에서 바로 라이브 영상을 보고, 필요하면 전체화면으로 전환한다. 영상은 사용자가 시청을 요청한 동안에만 송출된다.

| ID | 요구사항 | 관련 기능 |
|---|---|---|
| REQ-F-18 | 사용자는 요청한 시점에만 홈캠의 실시간 영상을 홈 화면 카드 또는 전체화면으로 볼 수 있다. | FN-A10, FN-A11, FN-A37, FN-S16, FN-S17, FN-S25, FN-E04, FN-E05 |
| REQ-F-41 | 사용자는 홈/캘린더/추억/가족/설정 탭을 이동하고, 화면을 당겨서 데이터를 새로고침할 수 있다. | FN-A06 |

### 1.4 이벤트(웃음) 감지 영상 확인

사용자는 집에 없는 사이 감지된 웃음 순간을 앱에서 목록으로 확인하고 재생한다. 젯슨이 웃음소리를 감지하면 전후 구간을 클립으로 만들어 자동 업로드한다.

| ID | 요구사항 | 관련 기능 |
|---|---|---|
| REQ-F-37 | 사용자는 홈캠 앞에서 웃음이 감지되면 별도 조작 없이 자동으로 영상 클립이 촬영·저장되는 것을 기대할 수 있다. | FN-E06, FN-E07, FN-S11, FN-S25 |
| REQ-F-21 | 사용자는 저장된 영상을 홈캠/웃음 감지/편집 완료 등으로 필터링·검색·정렬해 목록으로 볼 수 있다. | FN-A15, FN-S12 |
| REQ-F-22 | 사용자는 처리 완료된 저장 영상을 상세 화면에서 재생할 수 있다. | FN-A17, FN-A37, FN-S14 |

### 1.5 영상 편집

사용자는 확인한 웃음 클립을 폰에서 직접 편집한다. 자동 하이라이트나 AI 보정 없이, 사람이 폰 내 편집기(Banuba)로 수동 편집하는 방식이 목표다.

| ID | 요구사항 | 관련 기능 |
|---|---|---|
| REQ-F-27 | 사용자는 저장된 영상을 폰 내 편집기(Banuba)에서 화면 비율 변환 등 수동으로 편집할 수 있다. | FN-A21 |

### 1.6 편집 영상 다운로드

사용자는 편집된 영상을 갤러리에 저장하고 SNS·메신저로 공유한다. 원본 클립이 필요하면 서버에서 별도로 다운로드한다.

| ID | 요구사항 | 관련 기능 |
|---|---|---|
| REQ-F-26 | 사용자는 저장된 원본 영상을 기기(단말)로 다운로드할 수 있다. | FN-A20, FN-S14 |
| REQ-F-27 (로컬 저장·공유 측면) | 사용자는 편집을 마친 영상을 기기 갤러리에 저장하고, SNS·메신저 등 외부 앱으로 바로 공유할 수 있다. | FN-A21 |

### 1.7 통계 / 리포트

사용자는 웃음 감지 데이터를 기반으로 한 통계와 리포트를 확인한다. 현행 캘린더 집계·웃음 통계에 더해, 이벤트 감지 영상을 토대로 한 전용 리포트 화면을 신규 목표로 추가한다.

| ID | 요구사항 | 관련 기능 |
|---|---|---|
| REQ-F-19 | 사용자는 월별 캘린더에서 날짜별로 저장된 영상 개수를 확인하고, 날짜를 선택해 해당일 영상 목록을 볼 수 있다. | FN-A13, FN-S12 |
| REQ-F-36 | 사용자는 기간별 웃음 감지 통계(월 평균, 전체 포착 수, 주간 추이)와 연간 히트맵(웃음 잔디)을 확인할 수 있다. | FN-A36, FN-S15, FN-S22 |
| REQ-F-42 | 사용자는 이벤트 감지 영상을 토대로 제공되는 전용 통계/리포트 화면(주간/월간 웃음 횟수, 시간대별 분포, 베스트 클립 등)을 볼 수 있다. | FN-A38, FN-S26 (신규 — API-51 [제안], `04-API명세서.md` 8절) |

### 1.8 가족 공유

기기 단위로 OWNER / EDITOR / VIEWER 3개 역할이 존재한다. 가입은 초대 승인제로만 이루어지며, 링크만으로 자동 가입되는 경로는 없다.

| ID | 요구사항 | 관련 기능 |
|---|---|---|
| REQ-F-28 | 사용자는(OWNER) 이메일과 역할(EDITOR/VIEWER)로 가족 구성원을 초대하고, 구성원 목록·보낸 초대 목록을 확인할 수 있다. | FN-A22, FN-S07, FN-S10 |
| REQ-F-29 | 사용자는(OWNER) 아직 수락되지 않은(PENDING) 보낸 초대를 취소할 수 있다. | FN-A23, FN-S07 |
| REQ-F-30 | 사용자는(OWNER) 구성원을 기기에서 강제로 내보낼 수 있다(OWNER 본인 제외). | FN-A24, FN-S10 |
| REQ-F-31 | 사용자는 자신이 받은 초대 목록을 확인하고 수락 또는 거절할 수 있다. | FN-A25, FN-S09 |
| REQ-F-11 | 사용자는 "내 계정으로 초대해달라"는 멤버십 요청 링크를 만들어 외부로 공유할 수 있다. 단 이 링크 자체는 멤버십을 생성하지 않으며, OWNER가 이메일 지정 초대를 별도로 승인해야 한다. | FN-A08, FN-S08 |
