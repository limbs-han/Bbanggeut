# 모바일 자동 영상 편집기 구현

작성일: 2026-08-02

## 사용자 흐름

1. 사용자가 영상의 `편집`을 누른다.
2. 앱은 원본 미리보기를 준비하면서 로컬 Docker의 `POST /v1/edit-recommendations`를 호출한다.
3. 응답의 시작·끝 구간과 줌 구간을 하나의 `EditorProject`에 적용한다.
4. 사용자는 컷 순서, 화면 비율과 위치, 수동 텍스트, 줌 구간을 수정한다.
5. 재생은 컷으로 줄어든 편집 타임라인을 원본 시각으로 변환하고 해당 시각의 줌을 즉시 보여 준다.
6. 저장은 같은 프로젝트를 Android Media3 렌더러에 넘기고, 사용자 recipe revision을 로컬 MinIO에 저장한다.

## 편집 계약

- 컷은 원본 기준 `sourceStartMs`, `sourceEndMs`로 저장한다.
- 컷 목록 순서가 미리보기와 Media3 내보내기의 실제 연결 순서다.
- 줌은 원본 기준 시작·끝, 배율, 정규화 초점 좌표로 저장한다.
- 여러 컷으로 편집해도 내보낼 때 줌 구간과 각 클립의 교집합을 계산해 편집 타임라인 시각으로 변환한다.
- 미리보기와 내보내기는 같은 배율과 초점 좌표를 사용한다.
- 자동 편집 화면은 9:16 세로 캔버스와 `가로 영상 전체 보기`로 시작한다.
- 가로 원본은 세로 캔버스 가운데의 고정된 영상 창에 표시한다.
- 구간 줌은 고정된 가로 영상 창 안에서만 확대하고 위아래 검은 영역을 침범하지 않는다.
- Android 저장은 구간 줌을 세로 캔버스 합성 전에 적용해 미리보기와 같은 영상 창 경계를 유지한다.
- 위아래 검은 영역에는 텍스트와 자막 레이어를 배치할 수 있다.
- 텍스트와 영상 위치는 중앙선·안전 영역에 스냅하고 회전은 주요 각도에 스냅한다.
- 자동 추천이 실패하면 편집 진입을 막지 않고 전체 원본으로 연다.

## 편집 화면 표시와 조작

- `짧게`, `중간`, `길게`는 별도 숫자 막대를 만들지 않고 전체 타임라인 상단에 통합한다.
- 전체 타임라인의 `-1f`, `+1f` 버튼은 30fps 홈캠 원본을 한 프레임 단위로 이동한다.
- 컷 손잡이와 줌 구간 슬라이더도 30fps 프레임 경계에 맞춰진다.
- 추천 컷은 `추천 시작`, `추천 끝` 고정 마커로 표시한다. 사용자가 컷 손잡이를 움직여도 추천 마커는 움직이지 않는다.
- 추천·수동 줌은 파란 타임라인 밴드와 줌 목록으로 표시하고 시작·끝, 배율, 초점 X/Y를 수정한다.
- 모든 도구 탭에서 전체 타임라인을 유지한다.
- 위 트랙은 클립 번호와 가위 모양 컷 경계를 표시한다.
- 아래 트랙은 파란 줌 구간과 보라색 자막·텍스트 구간을 표시한다.
- 선택한 컷은 드래그 핸들 또는 좌우 이동 버튼으로 실제 배열을 바꾸며 저장 결과에도 같은 순서를 사용한다.
- 컷 손잡이는 시스템 뒤로가기 제스처 영역에서 안쪽으로 띄우고 추천·줌·재생 위치·영상 양끝에 스냅한다.
- `캔버스` 도구는 원본, 9:16, 16:9와 확대, X/Y 이동, 회전을 제공한다. 1:1과 4:5는 노출하지 않는다.
- 영상 화면의 이동·확대·회전 제스처는 `캔버스` 탭에서만 받는다.
- 캔버스와 구간 줌 패널은 `바로 적용` 상태를 표시하고 미리보기와 저장 recipe에 즉시 반영한다.
- 텍스트 도구는 이미 만든 레이어 목록을 보여 주며 목록 또는 영상 위 레이어를 눌러 다시 편집한다.
- 미리보기에는 중앙 정렬선, 안전 영역, 회전 각도 가이드를 표시한다.

## 제거한 범위

- Banuba SDK와 번들 효과 리소스
- 온디바이스 Whisper 의존성
- 181MiB 한국어 STT 모델
- 자동 자막 화면과 관련 테스트

자동 자막은 제공하지 않는다. 텍스트 도구로 사용자가 원하는 문구를 직접 추가한다.

## 로컬 검증 환경

- Android 실기기: `adb reverse tcp:18080 tcp:18080`
- 편집 추천 API: `http://127.0.0.1:18080`
- 저장소: 로컬 Docker MinIO
- 고정 검증 데이터: 2026-07-27~31의 다섯 영상 분석 JSON

타임라인 조작 원칙은 iMovie 모바일의 상세 타임라인 탐색과 Premiere의 프레임 단위 트림 버튼을 참고했다.

- iMovie 타임라인 탐색: https://support.apple.com/guide/imovie-iphone/navigate-in-the-timeline-knaeca4b0ea2/ios
- Premiere 트림 모드: https://helpx.adobe.com/premiere/desktop/edit-projects/trim-clips/about-trim-mode.html

Flutter 정적 분석과 전체 테스트 142개가 통과했다.

갤럭시 S24+ 실기기 확인은 이전 편집기 개편 기준이다.
