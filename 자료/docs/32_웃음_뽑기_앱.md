# 웃음 뽑기 앱

- 하단의 커뮤니티 탭에서 웃음 뽑기 화면을 연다.
- 가족 금고가 없으면 가족 연결 안내 화면을 표시한다.
- 최근 웃음 영상 하나를 무작위로 조회한다.
- 당일 뽑은 영상 ID를 기기에 저장해 화면을 다시 열어도 결과를 복원한다.
- 사용자는 영상에 이모지 반응 하나를 남기거나 다른 반응으로 변경할 수 있다.
- 추첨 시작과 완료 효과음은 앱에 포함된 자체 합성 WAV 파일을 사용한다.
- 영상 썸네일은 짧은 영상에서도 실패하지 않도록 영상 길이에 비례한 시점에서 생성한다.
- 원격 호출은 기존 인증과 토큰 재발급이 적용된 HTTP 클라이언트를 재사용한다.
