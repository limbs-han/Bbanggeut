# 웃음 뽑기

## 기능

- 가족의 최근 웃음 영상 중 하나를 무작위로 보여준다.
- 기본 조회 기간은 최근 3일이다.
- 조회 기간은 최대 7일까지 지정할 수 있다.
- 같은 화면에서 이미 본 영상 ID를 후보에서 제외할 수 있다.
- 후보 영상이 없으면 오류 대신 `hasMemory=false`를 반환한다.
- 사용자는 영상에 이모지 반응 하나를 남길 수 있다.
- 같은 영상에 다른 반응을 선택하면 기존 반응이 변경된다.
- 같은 반응을 다시 보내도 반응 수는 중복 증가하지 않는다.

## API

- `GET /api/families/{familyId}/laugh-memories/random`은 무작위 웃음 영상을 조회한다.
- `GET /api/laugh-memories/{memoryId}`는 저장된 웃음 영상을 다시 조회한다.
- `PUT /api/laugh-memories/{memoryId}/reaction`은 사용자의 이모지 반응을 저장한다.

## 앱 동작

- 하단의 커뮤니티 탭에서 웃음 뽑기 화면을 연다.
- 가족 금고가 없으면 기존 가족 연결 안내 화면을 표시한다.
- 추첨 중 효과음은 앱에 포함된 자체 합성 WAV 파일을 사용한다.
- 당일 뽑은 영상 ID를 기기에 저장해 화면을 다시 열어도 같은 결과를 복원한다.
- 영상 썸네일은 영상 길이에 맞춘 안전한 시점에서 생성한다.

## 데이터

- `laugh_memory_reactions`는 영상과 사용자 조합당 반응 하나만 저장한다.
- 반응 타입은 `FUNNY`, `MISS_THIS`, `GOOD_SAVE`, `EMBARRASSING`, `AGAIN`이다.
