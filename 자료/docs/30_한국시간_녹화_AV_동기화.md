# Jetson 한국시간 녹화와 A/V 동기화

## 녹화 시간대

- `RECORDING_TIMEZONE` 기본값은 `Asia/Seoul`이다.
- `local-recording.sh`는 `Asia/Seoul` 벽시로 `homecam-YYYYMMDDTHHMMSS.ts` 파일명을 생성한다.
- `segment_clip_uploader.py`는 같은 `RECORDING_TIMEZONE`으로 파일명을 해석한 뒤 UTC 이벤트 시각과 비교한다.
- 녹화기와 업로더의 `RECORDING_TIMEZONE`은 항상 같아야 한다.

## A/V 타임스탬프

- V4L2 영상은 `-timestamps abs`로 Unix wall-clock 기준 PTS를 사용한다.
- FFmpeg `-copyts`로 V4L2 영상과 ALSA 오디오의 실제 상대 시작 차이를 유지한다.
- 영상과 오디오에 각각 `PTS-STARTPTS`를 적용하지 않는다.
- `aresample=async=1`은 오디오 샘플과 PTS 사이의 작은 누적 차이를 보정한다.
