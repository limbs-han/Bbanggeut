# 복합 영상 이벤트 앱 표시

## 목적

한 구간에서 웃음과 연속 박수가 함께 감지되면 서버는 영상 하나에 여러 이벤트 유형을 기록할 수 있다. 앱은 이 영상을 중복 항목으로 만들지 않고 하나의 추억으로 표시하되, 사용자가 포함된 상황을 모두 알 수 있어야 한다.

## 응답 호환

- `triggerType`은 기존 앱과의 호환을 위한 대표 이벤트 유형이다.
- `eventTypes`는 영상에 포함된 전체 이벤트 유형 배열이다.
- `eventTypes`가 없는 기존 서버 응답은 `[triggerType]`으로 처리한다.
- 중복 값은 앱 모델 변환 단계에서 제거하고 대표 이벤트 유형을 첫 항목으로 유지한다.

## 화면 동작

- 목록, 카드, 상세 화면에서 `eventTypes`의 각 값을 별도 배지로 표시한다.
- `CLAP`은 `박수`, `LAUGHTER`는 `웃음`으로 표시한다.
- 웃음 리포트와 웃음 추억 필터는 대표 타입만 비교하지 않고 `eventTypes`에 `LAUGHTER`가 포함됐는지 확인한다.
- 따라서 대표 타입이 다른 복합 이벤트도 웃음이 포함됐다면 웃음 통계에 반영된다.
