## 2. 결과 상태 규칙

| 상태 | 사용 조건 |
| --- | --- |
| `미실행` | 아직 절차를 실행하지 않았거나 증거가 없다. 기본값이다. |
| `통과` | 계획된 절차를 실행했고 실제 결과가 예상 결과와 일치하며 증거가 있다. |
| `실패` | 실행했으나 예상 결과와 불일치한다. 결함 ID를 연결한다. |
| `차단` | 환경·선행 기능·장비 문제로 절차를 완료하지 못했다. 차단 사유를 기록한다. |
| `해당 없음` | 범위에서 공식 제외되었다. 승인자와 근거를 기록한다. |

`미실행`, `차단`, `해당 없음`은 통과율의 통과 건수에 포함하지 않는다.
