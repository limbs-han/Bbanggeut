William James API (1.2.0)

Download OpenAPI specification:

웃음·호출어·터치 이벤트로 생성된 영상을 관리하는 모바일·IoT API다.

권한의 기준은 기기다. 사용자와 기기는 DeviceMembership으로 다대다 연결되며, 사용자는 여러 기기에 서로 다른 역할로 참여할 수 있고 한 기기도 여러 사용자가 공유할 수 있다.

  • Flutter 앱은 UserBearerAuth JWT를 사용한다.
  • IoT 기기는 사용자 JWT와 분리된 DeviceBearerAuth 자격 증명을 사용한다.
  • 대상 기기의 활성 멤버십이 없으면 정보 은닉을 위해 404로 응답한다.
  • 같은 기기의 활성 구성원이지만 OWNER 전용 작업을 수행할 역할이 부족하면 403으로 응답한다.
  • 객체 저장소는 비공개이며 권한 확인 후 단기 서명 URL만 발급한다.
  • IoT 영상 업로드는 MVP에서 단일 PUT, 파일당 최대 500 MiB다.

Streaming

활성 시청자가 있을 때만 동작하는 실시간 보기 세션

온디맨드 실시간 보기 세션 시작

OWNER 또는 MEMBER의 활성 기기 멤버십을 확인한 뒤 시청자 세션을 만든다. 이미 같은 기기의 송출이 있으면 하나의 edge 송출을 여러 시청자가 공유하고 MQTT START를 다시 보내지 않는다. 최초 시청자는 MQTT START 후 HLS 세그먼트가 준비될 때까지 수초간 PENDING일 수 있다.

앱은 응답의 주기(권장 15초)로 heartbeat를 보내야 한다. 마지막 시청 활동 시각 (유효 heartbeat 또는 정상 종료)을 기준으로 60초 동안 새 시청자가 없으면 서버가 MQTT STOP을 보낸다. 생성 직후 첫 heartbeat 전에는 createdAt을 초기 lastActivityAt으로 사용해 viewerExpiresAt=createdAt+45초, STOP deadline=createdAt+60초로 계산한다. heartbeat가 45초 끊긴 세션을 먼저 만료시키되 idle 시간을 추가로 60초 더하지 않는다. 세션 상태 저장소는 인메모리·DB 등 구현 선택이며 Redis를 필수로 요구하지 않는다. edge 송출은 기본 120초의 hard timeout을 가지며 활성 시청자가 있으면 서버가 hardExpiresAt을 만료 전에 연장한다.

실시간 보기 시청자 heartbeat

앱은 15초마다 호출한다. 서버는 시청자 TTL을 갱신하며, heartbeat가 약 45초 동안 없으면 비정상 종료된 세션을 EXPIRED로 회수한다. 마지막 시청자의 경우 마지막 유효 heartbeat부터 총 60초가 되는 시점에 STOP하도록 예약하며, 45초 만료 뒤 60초를 추가하지 않는다. JWT 사용자가 이 세션을 만든 사용자와 같은지와 세션 기기의 활성 멤버십을 모두 다시 확인한다. 다른 사용자의 sessionId 또는 회수된 멤버십은 404로 숨긴다.
