## 2. 범위 통제 원칙

1. [기본] 기능의 핵심 경로가 끝까지 연결되기 전에는 [심화] 구현을 시작하지 않는다.
2. 호출어가 불안정해도 터치 센서로 동일한 저장 시나리오를 유지한다.
3. Pi↔Jetson 통합이 지연되면 Jetson 한 보드에 터치·LED를 연결한다.
4. HLS가 지연되면 저장 영상 재생·다운로드를 먼저 완성하고 스트리밍을 후순위로 둔다.
5. 7월 29일부터 신규 심화 기능을 금지하고 결함 수정·문서·시연에 집중한다.
6. PM 승인 없이 기본 기능의 인수 기준을 변경하지 않는다.

## 10. 공통 Definition of Done

작업은 코드 작성만으로 완료 처리하지 않는다.

- [ ] 요구사항·인수 기준과 일치한다.
- [ ] 정상·실패·권한·빈 상태를 처리한다.
- [ ] 관련 단위 또는 통합 시험이 있고 결과가 기록된다.
- [ ] 개인정보·토큰·영상 URL이 로그와 화면에 불필요하게 노출되지 않는다.
- [ ] API·이벤트·배선 계약 변경이 문서에 반영된다.
- [ ] 다른 직무 소비자가 실제 연동해 확인했다.
- [ ] 재현 가능한 실행·배포 방법이 있다.
- [ ] 알려진 제한·미해결 항목이 숨김없이 기록된다.
- [ ] PM 또는 지정 리뷰어가 인수 기준을 확인했다.
