# Jetson 미디어 A/V 동기화

## 적용 범위

- `ai/device_agent/media-source.sh`가 USB 카메라와 마이크를 한 번만 열어 H.264/AAC MPEG-TS로 분기한다.
- 이 설정은 YOLO, YAMNet, 라이브 송출, 로컬 MediaMTX가 공유하는 원본 스트림에 모두 적용된다.

## 타임스탬프 규칙

- V4L2 영상 입력은 `-timestamps abs`를 사용해 커널의 monotonic PTS를 Unix wall-clock 기준으로 변환한다.
- ALSA 오디오 PTS는 Unix wall-clock 기준을 유지한다.
- 영상은 `setpts=PTS-STARTPTS`로 첫 프레임을 0으로 정규화한다.
- 오디오는 `asetpts=PTS-STARTPTS`로 첫 샘플을 0으로 정규화한다.
- 오디오만 `first_pts=0`을 강제하는 비대칭 설정은 사용하지 않는다.
- `aresample=async=1`은 오디오 샘플과 PTS 사이의 작은 차이를 계속 보정한다.

## 검증

- `bash -n ai/device_agent/media-source.sh`로 Shell 문법을 검사한다.
- `python3 -m unittest discover -s ai/device_agent/tests -v`로 타임스탬프 설정 회귀 테스트를 실행한다.
- Jetson 실기에서 스트림 시작 직후와 1시간 이후에 박수 영상으로 체감 A/V 오차를 확인한다.
- FFmpeg 로그에 `ALSA xrun`, input queue blocking, non-monotonic timestamp 경고가 없는지 확인한다.
