# 젯슨 엣지 AI 릴리스 절차

## 1. 배경

젯슨 엣지 AI 코드 배포는 지금까지 손으로 해 왔고 절차가 저장소에 없었다.
그 기계에 접근하는 사람이 없으면 아무도 배포할 수 없는 상태였다.

`ai/device_agent/release-edge-ai.sh`가 그 절차다.

## 2. 구조

릴리스는 디렉터리를 덮어쓰지 않고 새로 만든 뒤 링크를 옮긴다.

```
~/ai -> ~/ai_releases/<UTC타임스탬프>_<브랜치>_<짧은커밋>
```

이름에 커밋이 박혀 있고 릴리스 안에 `DEPLOYED_COMMIT` 파일이 남으므로, 돌고
있는 코드가 어느 커밋인지 기기에서 바로 확인할 수 있다.

롤백은 파일 복원이 아니라 링크 되돌리기다.

## 3. 전제

젯슨 안에 저장소 체크아웃이 있어야 한다. 기본 경로는 `~/william-james`다.

```bash
git clone https://lab.ssafy.com/s15-webmobile3-sub1/S15P11E201.git ~/william-james
```

다른 위치를 쓰려면 `--repo` 또는 `WJ_REPO_DIR`로 지정한다.

체크아웃에서 뽑는 이유는 두 가지다. 배포된 내용이 어느 커밋인지 보장되고,
윈도우에서 만든 파일이 CRLF로 올라가는 문제가 없다.

## 4. 사용

```bash
# 미리보기. 스냅샷을 만들고 검증까지 하되 링크는 그대로 둔다.
bash ~/william-james/ai/device_agent/release-edge-ai.sh --ref develop

# 링크 교체까지
sudo bash ~/william-james/ai/device_agent/release-edge-ai.sh --ref develop --apply

# 서비스 재시작까지
sudo bash ~/william-james/ai/device_agent/release-edge-ai.sh --ref develop --apply --restart
```

기본은 미리보기다. `--apply` 없이는 링크를 건드리지 않는다.

## 5. 안전장치

- `validate_jetson_release.sh`가 통과해야만 링크를 교체한다. 실패하면 만들어진
  릴리스를 남긴 채 중단하므로 원인을 그 자리에서 확인할 수 있다.
- 검증기는 `${HOME}/venvs/...`를 확인한다. root로 돌리면 `HOME`이 `/root`가
  되어 실제 venv를 못 찾으므로, 스크립트가 대상 사용자 권한으로 실행한다.
- 저장소 `ai/`에 커밋되지 않은 변경이 있으면 경고한다. `git archive`는 커밋된
  내용만 담으므로 그 변경은 배포되지 않는다.
- `~/ai`가 심볼릭 링크가 아니라 실제 디렉터리이면 `--apply`가 거부한다. 손으로
  밀어 넣은 코드를 링크로 덮어써서 지우지 않기 위해서다.

## 6. 최초 도입

`~/ai`가 아직 실제 디렉터리라면 한 번 옆으로 치워야 한다.

```bash
sudo systemctl stop wj-edge-ai-recording.service
sudo mv ~/ai ~/ai.manual-$(date -u +%Y%m%dT%H%M%SZ)
sudo bash ~/william-james/ai/device_agent/release-edge-ai.sh --ref develop --apply --restart
```

치워 둔 디렉터리는 새 릴리스가 정상 동작하는 것을 확인한 뒤에 지운다.

## 7. 롤백

```bash
sudo ln -sfn ~/ai_releases/<이전_릴리스> ~/ai
sudo systemctl restart wj-edge-ai-recording.service
```

오디오 판정 모델만 되돌리려면 코드 롤백 없이 기기 env를 고친다.

```
AUDIO_EVENT_MODEL=yamnet
```

## 8. 주의

기기 env(`/etc/william-james/device-agent.env`)는 이 절차의 대상이 아니다.
env가 저장소 기본값을 항상 이기므로, 코드를 배포해도 env에 박힌 값은 그대로
남는다. 값을 바꾸려면 env 수정과 서비스 재시작이 따로 필요하다.
