## 사용 원칙

- 4개 파일(01~04)은 서로 참조하되 독립적으로도 읽을 수 있게 작성되었다 — 필요한 파일만 발췌해 붙여도 되고, 전체 그림이 필요하면 순서대로 이어붙여도 무방한 구조다(ID 중복 정의 없음, 상호 링크만 존재).
- ID(REQ-F/NF, FN-A/S/E/H, API, MQTT)는 4개 문서 및 사람용 원본(`docs/human/`) 전체에서 동일하게 유지된다. 코드 변경 시 사람용 원본을 먼저 갱신하고, 본 디렉터리는 그 파생본이므로 함께 갱신할 것.
- 🔴(클라이언트 호출·서버 부재), 🔶(서버 구현·클라이언트 미사용), ❌(미구현), ⚠️(미확인) 표시는 반드시 그대로 유지한다 — 없는 기능을 있다고 가정하고 코드를 작성하지 말 것. 특히:
  - `API-06`(`PATCH /api/auth/me`)은 서버에 없다.
  - `homecam/v2`(MQTT-10~15, FN-E08/E09) 파이프라인은 운영에서 비활성 상태다.
  - 팬틸트(FN-H02~H04)는 서보 구동 코드가 없다.
  - 소셜로그인/비밀번호찾기/비밀번호변경/기념일저장 4개 프런트 기능은 스텁(로컬 스낵바만)이다.
