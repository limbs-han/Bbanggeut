## 1. 프로젝트 아이디어 제안

### 공장·물류센터 화재 직전 상황 기록 및 구조 지원 로봇

공장과 물류센터에서 화재가 발생했을 때, 로봇이 화재 이후 위험 구역에 진입하는 방식은 현실성이 낮다고 판단했습니다.  
이에 평상시 로봇이 작업장을 순찰하며 사람의 위치와 인원 정보를 기록하고, 화재가 감지되면 화재 직전까지 수집된 마지막 위치 정보를 관리자와 구조대에 제공하는 아이디어를 제안했습니다.


### 프로젝트 기힉 및 서비스 구체화

- 팀 회의를 통해 서비스 아이디어를 구체화하고 프로젝트의 방향성 정리
- 서비스 방향성 및 핵심 기능 구체화
- 컨설팅 피드백을 반영하여 서비스의 필요성과 차별점 보완

## 2. 회의록 기록 및 프로젝트 문서화

회의 내용을 기록하고 문서화하여 팀원들이 동일한 기준으로 개발을 진행할 수 있도록 정리했습니다.

### 주요 수행 내용

- 프로젝트 아이디어 회의 내용 기록
- 팀원별 의견 및 반대 의견 정리
- 프로젝트 방향 변경 과정 문서화
- 컨설팅 피드백 반영 내용 정리

### 문서화 목적

- 팀원 간 서비스 이해도 향상
- 의사결정 과정 및 변경 이력 관리
- 개발 진행을 위한 공통 기준 마련
- 프론트엔드, 백엔드, AI, IoT 파트 간 협업 효율 향상

## 3. Flutter 학습

모바일 애플리케이션 개발을 위해 Flutter와 Dart 학습을 시작했습니다.

기존 Vue 기반 웹 프론트엔드 경험을 바탕으로 Flutter의 위젯 구조와 모바일 UI 개발 방식을 학습했습니다.

### 학습 내용

- Flutter 및 Dart 기본 개념
- Flutter 프로젝트 구조
- Widget 기반 UI 구성
- 버튼, 입력창, 카드, 리스트 등 기본 위젯 활용
- Navigator를 이용한 화면 전환
- 반응형 모바일 UI 설계
- HTTP 기반 API 통신 방식
- Android 앱 실행 및 빌드 환경 구성

### 프로젝트 적용 목표

- 로그인 및 회원가입 화면 구현
- IoT 기기 등록 화면 구현
- 영상 목록 및 상세 화면 구현
- 영상 재생, 편집, 다운로드 기능 구현
- 가족 구성원 및 권한 관리 화면 구현
- 모바일 환경에 최적화된 사용자 경험(UX) 제공
