## 공통 2주차 배운점

### 1. 프로젝트 아이디어 합의 과정

이번 주에는 AIoT 프로젝트의 아이디어를 구체화하고 팀원들과 프로젝트 방향을 합의하는 과정에 집중했다.

초기에는 팀원마다 생각하는 프로젝트의 방향이 달라 의견을 하나로 모으는 데 어려움이 있었다. 하지만 의견이 바로 반영되지 않는 것을 두려워하지 않고, 프로젝트에 적합하다고 생각하는 아이디어를 지속적으로 제안했다.

동시에 내 아이디어만 고집하거나 특정 아이디어에 매몰되지 않도록 의식적으로 열린 태도를 유지했다. 각 아이디어의 장단점과 실제 구현 가능성을 함께 살펴보며 팀원들의 의견을 이해하려고 노력했고, 그 결과 팀이 동의할 수 있는 방향으로 합의를 이끌어 낼 수 있었다.

프로젝트 아이디어가 결정된 이후에는 이전에 제안했던 다른 아이디어에 미련을 두지 않았다. 팀이 합의한 아이디어를 구체화하고 완성도 높은 프로젝트로 발전시키는 데 집중했다.

### 2. 소통 과정에서의 노력

프로젝트를 진행하면서 이해하지 못한 내용은 그대로 넘어가지 않고, 정확하게 이해할 때까지 질문했다.

단순히 내 의견을 전달하는 것에 그치지 않고, 팀원들이 제안한 내용의 의도와 구현 방법을 이해하려고 노력했다. 이를 통해 서로의 생각을 명확하게 확인할 수 있었고, 프로젝트 방향에 대한 오해를 줄일 수 있었다.

이번 경험을 통해 원활한 협업을 위해서는 자신의 의견을 적극적으로 표현하는 것뿐만 아니라 상대방의 의견을 끝까지 듣고 이해하려는 태도도 중요하다는 것을 배웠다.

### 3. AI 담당자로서의 학습

이번 프로젝트에서 AI 포지션을 담당하게 되어 젯슨 오린 나노를 활용한 온디바이스 AI 구현 방법을 학습했다.

온디바이스 AI는 촬영한 데이터를 클라우드 서버로 전송하지 않고, 기기 내부에서 직접 AI 모델을 실행하는 방식이다. 이를 통해 인터넷 연결이 불안정한 환경에서도 기능을 사용할 수 있고, 영상 데이터를 외부로 전송하지 않아 개인정보 보호 측면에서도 장점이 있다는 것을 이해했다.

또한 제한된 하드웨어 환경에서 AI 기능을 구현하기 위해서는 단순히 정확도가 높은 모델을 선택하는 것보다 모델의 크기, 추론 속도, 정확도, 메모리 사용량을 함께 고려해야 한다는 점을 배웠다.

### 4. AI 모델 적용 계획 수립

프로젝트에 AI 기능을 어떻게 적용할 것인지 구체적인 계획을 수립했다.

먼저 카메라를 통해 사용자의 얼굴 영상을 입력받고, OpenCV를 활용해 영상 프레임을 가져온다. 이후 얼굴이 있는 영역을 탐지하고, 탐지된 얼굴 이미지만 웃음 감지 모델에 입력한다. 모델은 얼굴 표정을 분석하여 사용자가 웃고 있는지 판단하고, 판단 결과를 프로젝트의 다른 기능과 연결한다.

전체적인 처리 과정은 다음과 같다.

`카메라 영상 입력 → 얼굴 탐지 → 얼굴 이미지 추출 → 웃음 감지 모델 실행 → 웃음 여부 판단 → 결과 활용`

초기에는 이미 학습된 모델을 활용해 기능이 정상적으로 동작하는지 확인하고, 이후 프로젝트 환경에 맞는 데이터를 추가로 수집하여 모델을 학습하거나 성능을 개선할 계획이다.

또한 일반 PC 환경에서 먼저 모델을 테스트한 뒤, 젯슨 오린 나노에 모델을 옮겨 추론 속도와 메모리 사용량을 확인할 예정이다. 모델의 실행 속도가 충분하지 않을 경우 입력 이미지 크기를 줄이거나 TensorRT와 같은 최적화 기술을 적용하는 방법도 검토할 계획이다.

### 5. 젯슨 오린 나노에서 웃음 감지 모델이 동작하는 과정

젯슨 오린 나노는 카메라로 들어온 영상을 실시간으로 처리하면서 AI 모델을 실행할 수 있는 소형 컴퓨터이다.

카메라가 사용자의 얼굴을 촬영하면 OpenCV가 영상에서 얼굴 부분을 찾아낸다. 이후 웃음 감지 모델이 해당 얼굴 이미지를 분석하여 `웃음` 또는 `웃지 않음`으로 분류한다. 젯슨 오린 나노의 GPU를 활용하면 이러한 과정을 기기 내부에서 빠르게 반복하여 실시간으로 웃음을 감지할 수 있다.

즉, 젯슨 오린 나노는 다음과 같은 역할을 수행한다.

`카메라로 얼굴 확인 → AI 모델로 표정 분석 → 웃음 여부 판단 → 판단 결과 전달`

웃음이 감지되면 화면에 결과를 표시하거나 특정 기능을 실행하는 등 프로젝트의 서비스 로직과 연결할 수 있다.

### 6. 이번 주에 배운 점

이번 주 프로젝트를 통해 아이디어가 받아들여지지 않는 상황을 실패로 받아들이기보다 더 좋은 결과를 만들어 가는 협업 과정으로 바라보는 태도를 배웠다.

내 의견을 적극적으로 제안하되, 팀의 결정이 내려진 이후에는 개인적인 아쉬움보다 공동의 목표를 우선해야 한다는 점도 느꼈다. 또한 모르는 내용을 숨기거나 넘어가지 않고 끝까지 질문하는 것이 개인의 이해뿐만 아니라 팀 전체의 소통에도 도움이 된다는 것을 알게 되었다.

기술적으로는 젯슨 오린 나노와 온디바이스 AI의 기본 개념을 학습하고, 웃음 감지 모델을 프로젝트에 적용하기 위한 전체 처리 과정을 설계했다. 이를 통해 AI 모델을 선정하는 것뿐만 아니라 입력 데이터 처리, 모델 추론, 결과 활용, 하드웨어 최적화까지 함께 고려해야 한다는 점을 배울 수 있었다.
