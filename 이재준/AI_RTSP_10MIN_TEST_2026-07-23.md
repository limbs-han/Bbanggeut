## 성능 해석

- 시작 표본의 GPU 사용률은 98%, 종료 표본은 8%로 변동 폭이 컸다.
  순간 표본이므로 평균 GPU 사용률로 해석하지 않는다.
- 종료 표본에서 CPU 6개 코어가 각각 약 85~94%를 기록했다.
- YOLO 프로세스의 누적 CPU 사용률은 164%에서 311%로 상승했다.
- 온도는 약 50°C로 안정적이고 스왑은 사용하지 않았다.
- 10분 동안의 RAM 증가는 모델 워밍업·캐시 가능성이 있어 메모리 누수로
  판정하지 않는다. 1시간 이상 시험에서 증가 추세를 다시 확인한다.
- 1080p 전환 전에는 YOLO 처리 FPS 제한, 추론 입력 크기, 캡처 H.264
  하드웨어 인코딩 가능성을 우선 검토한다.

## 남은 확인

- MediaMTX 강제 종료 시 `NRestarts` 증가와 녹화기 재연결 기록을 확인한다.
- 1시간 연속 실행으로 FPS, YAMNet 추론 지연, 평균·최대 자원 사용량을
  확정한다.
- 기존 5초 MVP 업로더의 HTTP 409 응답 계약과 지수 백오프를 구현한다.
- 1시간 시험 전에는 기존 UDP fallback을 제거하거나 부팅 기본값을
  RTSP 기반 AI로 전환하지 않는다.
