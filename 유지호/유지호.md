## 1. 아이디어 발제

브레인스토밍 단계에서 아래 주제들을 제안하고, 각 주제의 문제 정의·핵심 기능·AIoT 적합성을 정리했다. 이 후보들은 대안 검토였고, **최종 확정된 주제는 팀의 원래 아이디어인 윌리엄 제임스**다.

### 무인 매장 관리 시스템
- **문제 정의**: 무인 매장은 사람이 상주하지 않아 도난·재고 파악·이상 상황 대응이 취약하다.
- **핵심 기능**: 카메라 기반 객체 탐지로 방문객·상품 이동 감지 → 비정상 행동 탐지 시 알림 → 재고 카운팅 자동화.
- **AIoT 적합성**: 객체 탐지(비전 AI) + 엣지 디바이스(카메라·센서) + 관리자 대시보드(웹).

### 쓰레기 분리수거 보조 시스템
- **문제 정의**: 분리배출 기준이 복잡해 잘못 버려지는 재활용품이 많다.
- **핵심 기능**: 카메라로 쓰레기 촬영 → 이미지 분류로 재질(플라스틱/캔/유리/일반) 판별 → 올바른 분리함 안내·개폐.
- **AIoT 적합성**: 이미지 분류(AI) + 액추에이터 제어(IoT) + 사용 통계 시각화(웹).

### 반려동물 이상행동 감지 홈캠
- **문제 정의**: 홀로 둔 반려동물의 이상 상황(과도한 짖음, 낙상, 이상 자세)을 보호자가 즉시 알기 어렵다.
- **핵심 기능**: 홈캠 영상·음성에서 이상 신호를 온디바이스로 감지 → 이벤트 순간 자동 저장·알림 → 앱에서 확인.
- **AIoT 적합성**: 온디바이스 영상·음성 추론(AI) + 홈캠 하드웨어(IoT) + 이벤트 관리 앱.

### 발제 요약

| --- | --- | --- |

| 쓰레기 분리수거 | 이미지 분류 | 데이터 난이도 높음 |

| **윌리엄 제임스 (확정)** | **온디바이스 음성 분류(웃음)·영상 처리** | **최종 채택** |

## 2. 음성 분류 모델 테스트

- 오디오 이벤트 분류 모델(YAMNet 계열)을 로컬 환경에서 로드해 샘플 오디오로 추론 파이프라인을 구성.
- 웃음소리를 포함한 오디오 입력을 넣어 "Laughter" 계열 라벨이 분류 결과 상위에 잡히는지 확인.
- 입력 오디오의 전처리 요구사항(샘플링 레이트, 프레임 길이)과 출력 라벨 체계를 파악.
- 범용 오디오 분류 모델로 웃음소리 계열을 검출하는 접근이 유효함을 확인. 실제 생활 소음 환경에서의 오탐·미탐 검증은 추가 필요.

## 3. 라즈베리파이 연결 시도

- 라즈베리파이 초기 세팅(OS 이미지, 네트워크 연결, 원격 접속 환경)을 구성.
- 보드가 정상 부팅되고 원격에서 제어 가능한 상태까지 연결을 점검.
- 이후 마이크/카메라 입력과 음성 분류 모델을 이 보드 위에서 연동하는 구성 방향을 검토.
