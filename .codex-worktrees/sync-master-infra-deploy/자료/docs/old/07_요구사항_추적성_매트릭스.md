## 6. 변경 영향 확인 규칙

- 이벤트 구간 또는 세그먼트 길이가 바뀌면 `FR-B-002`, `FR-B-003`, `FR-B-004`, `FR-B-005`, `NFR-B-008`과 `TC-F-B-002`, `TC-F-B-003`, `TC-F-B-004`, `TC-F-B-005`, `TC-F-B-006`, `TC-N-B-007`, `TC-N-B-009`를 함께 검토한다.
- 기기별 `DeviceMembership` 권한 모델이 바뀌면 `FR-B-014`, `FR-B-015`, `FR-B-016`, `FR-B-017`, `NFR-B-004`, `NFR-B-009`와 `TC-F-B-018`, `TC-F-B-019`, `TC-F-B-020`, `TC-F-B-021`, `TC-F-B-022`, `TC-N-B-004`를 다시 실행한다.
- 저장소·서명 URL이 바뀌면 `FR-B-006`, `FR-B-010`, `NFR-B-003`, `NFR-B-006`, `NFR-B-012`를 다시 검증한다.
- 라이브의 PENDING 초기 `createdAt/lastActivityAt/viewerExpiresAt/stopDeadline`, 세션 소유자·ACTIVE 멤버십 기반 playlist/segment 인가, 15초 heartbeat·45초 TTL·최대 60초 stop·120초 `hardExpiresAt` 또는 HLS GOP 규격이 바뀌면 `FR-B-012`, `NFR-B-003`, `NFR-B-004`, `NFR-B-011`과 `TC-F-B-015`, `TC-F-B-020`, `TC-N-B-003`, `TC-N-B-004`, `TC-N-B-009`, `TC-N-B-010`을 다시 실행한다.
- 기기 등록 방식이 바뀌면 `FR-B-013`, `NFR-B-002`, `NFR-A-001`과 등록·기기 자격 증명 테스트를 갱신한다.
- 얼굴·생성·공유 기능을 활성화하면 심화 개인정보 테스트를 실행하기 전 운영 기본값이 비활성·비공개인지 먼저 확인한다.
