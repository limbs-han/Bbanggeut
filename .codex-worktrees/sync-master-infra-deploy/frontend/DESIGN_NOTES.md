# 디자인 적용 메모

기준 자료는 Figma `Warm Memory · Final`의 8개 화면과 `윌리엄 제임스 - 앱 와이어프레임.png`이다. 백엔드 OpenAPI와 실제 서버 동작을 우선하고 시안은 정보 구조와 따뜻한 분위기를 참고했다.

## 코드에서 개선한 점

- 작은 본문과 약한 대비를 보완하고, 최소 14px 본문·명확한 제목 계층을 사용했다.
- 360px 고정 배치 대신 스크롤과 최대 폭을 사용해 작은 Android 화면과 키보드 표시에도 대응했다.
- 홈을 대표 추억, 기기 상태, 보관 통계, 최근 영상, 라이브 진입 순으로 재구성했다.
- 색상은 크림 배경·딥 틸·민트·피치로 제한하고 카드 반경과 간격을 토큰화했다.
- Figma의 오래된 제품 코드 `WJ-8K4M-27QX`는 실제 API 규격인 일회용 `XXXX-XXXX`로 교체했다.
- 초대 링크만으로 즉시 구성원이 되는 것처럼 보이지 않도록 가입 요청과 OWNER 승인 상태를 분리했다.
- PENDING/READY/FAILED 라이브 상태와 오프라인·빈 목록·오류·로딩 상태를 실제 화면으로 추가했다.
- 단기 재생·다운로드 URL, 15초 라이브 heartbeat, 화면 이탈 시 세션 종료 등 보안 동작을 UI 문구와 함께 구현했다.
- 서버 편집 대신 원본을 기기 임시 저장소로 받은 뒤 로컬 구간 편집·공유하도록 변경했다.

## Figma에 역반영할 항목

- 로그인·회원가입을 각각의 상태 화면으로 분리
- 기기 등록 코드를 `XXXX-XXXX`로 수정하고 가족 초대 참여 흐름 추가
- 기기 없음, 영상 없음, 오프라인, API 오류, 로딩 skeleton 상태 추가
- 가입 요청 승인/거절과 초대 링크 만료 안내 추가
- 라이브 PENDING/FAILED/EXPIRED 상태와 세션 종료 안내 추가
- 설정에 구독, 접근 로그, 회원 탈퇴 OWNER 차단 안내 추가

현재 Figma Starter MCP 호출 한도로 원본 파일 자동 수정은 보류했다. 호출 한도가 복구되면 이 목록과 구현 화면을 기준으로 원본을 동기화한다.
