# AI 이벤트 영상 MVP 종단 검증 — 2026-07-27

## 한 줄 요약

Jetson Orin Nano와 Logitech BRIO 100에서 수동 이벤트와 실제 웃음 이벤트를
각각 전후 60초 MP4로 생성해 서버에 업로드하고, Flutter 앱에서 영상·음성 및
실제 웃음 구간을 재생하는 데 성공했다.

## 검증 범위

```text
BRIO 100 영상·음성
→ Jetson H.264/AAC 순환 녹화
→ YAMNet 웃음 감지
→ 전후 60초 MP4 생성
→ 업로드 URL 발급
→ 서버 저장소 업로드
→ 업로드 완료·READY 처리
→ Flutter 앱 목록 조회·재생
```

인증정보, 실제 기기 UUID, 이벤트 UUID와 영상 UUID는 이 문서에 기록하지 않는다.

## 환경

| 항목 | 값 |
| --- | --- |
| 엣지 장치 | NVIDIA Jetson Orin Nano 8GB |
| 카메라·마이크 | Logitech BRIO 100 |
| 영상 | H.264, 1280×720 |
| 음성 | AAC, 48kHz, mono |
| AI 입력 | `rtsp://127.0.0.1:8554/homecam/ai` |
| 웃음 점수 집계 | `mean` |
| 임계값 | `0.125` |
| 연속 판정 | `3` |
| 입력 gain | `1.5` |
| 이벤트 구간 | 최초 감지 60초 전부터 마지막 감지 60초 후 |

## 검증 결과

### 수동 이벤트

- 임의로 생성한 Trigger를 디스크 기반 업로더가 처리했다.
- 녹화 구간이 완성될 때까지 `waiting for recording coverage` 상태를 유지했다.
- 약 39MB의 MP4를 서버에 업로드하고 완료 영수증을 생성했다.
- Flutter 앱에서 약 2분 길이의 영상과 음성을 재생했다.
- 수동 시험 영상은 사용자의 선택에 따라 앱에 보관한다.

### 실제 웃음 이벤트

- BRIO 100 입력에서 YAMNet이 실제 웃음을 `Laughter`로 판정했다.
- 판정 직전의 연속 `mean` 점수는 `0.294`, `0.516`, `0.244`였다.
- 운영 기준 `mean / 0.125 / 3회`를 만족해 자동 Trigger가 생성됐다.
- 전후 60초 MP4가 서버에 업로드되고 완료 영수증이 생성됐다.
- Flutter 앱에서 영상·음성, 실제 웃음 구간과 약 2분 길이를 모두 확인했다.

### 업로드 성공 후 로컬 자동 정리

- Jetson 환경에 `DELETE_EVENT_AFTER_UPLOAD=true`를 적용했다.
- 업로더가 `--delete-after-upload` 옵션으로 실행되는 것을 확인했다.
- 별도 수동 이벤트를 서버에 업로드한 뒤 MP4와 Trigger가 자동 삭제됐다.
- 작은 `uploaded.json` 완료 영수증만 남아 재처리를 방지했다.
- Jetson 로컬 파일 정리는 서버와 앱의 영상 보관·재생에 영향을 주지 않는다.

## 발견한 검증 도구 문제

최초 시험용 명령은 `tail -n 0 -F`를 시작한 뒤 로그 한 줄을 기다렸다. 웃음
이벤트가 감시 프로세스 시작 경계에서 기록되면 명령은 `NOT_DETECTED`를 표시해도
실제 Trigger는 생성되는 경합이 있었다.

`yolo/validate_laughter_event_e2e.sh`는 로그가 아니라 시험 시작 이후 생성된
`*.trigger.json`을 감시한다. 따라서 빠른 이벤트를 놓치지 않으며 업로드 완료,
병합, 영구 차단, 서비스 종료와 timeout을 서로 다른 결과로 구분한다.

## 로컬 보관 정책

서버 업로드와 앱 재생에 성공한 영상은 서버에 보관한다. Jetson에는 중복 MP4와
Trigger를 장기 보관하지 않고, 재처리를 막는 작은 `uploaded.json` 영수증만
남기는 것을 운영 기준으로 한다.

이미 앱에 보관한 영상을 Jetson에서 정리해도 서버 영상은 삭제되지 않는다.
